# A3 – Virtualisation

## Objective
Evaluate virtualisation options for isolating and scaling portal services.

## Topics to cover
1. Type 1 (bare-metal) and Type 2 (hosted) hypervisors.
2. Full virtualisation and para-virtualisation.
3. Hardware assistance such as Intel VT-x and AMD-V.
4. Benefits: isolation, consolidation, snapshots, portability and recovery.
5. Costs: host overhead, memory reservation, licensing, storage and operational complexity.
6. Compare VirtualBox and KVM for development and production use.

## Evidence to add
- Hypervisor comparison table.
- Explanation of the selected approach for the university server room.
- If available, a screenshot of the hypervisor/VM configuration.
